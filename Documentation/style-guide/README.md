# 🎨 Style guide

Add the style guide here (PDF/PNG exports from Figma).

**Summary**

| Name | Hex | Use |
|---|---|---|
| Obsidian void | `#0D0D0D` | Backgrounds |
| Mystic violet | `#4C33A6` | Primary surfaces, selected states |
| Arcane gold | `#F2EA79` | Anything you can tap |
| Astral indigo | `#70468C` | Secondary accents |
| Parchment white | `#FDFAF5` | Text |
| Wrong / hurt | `#FF9B8F` | Wrong answers, damage |

- **Montserrat** for all text and numbers; **Cinzel** for short titles only.
- All text passes WCAG AAA contrast.
- Type scale: 13 helper · 16 body · 16 card title · 20 button · 24 heading · 30 screen title · 36 sum.
